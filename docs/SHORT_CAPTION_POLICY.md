# ショート動画の字幕方針（自動作成の「仕上げ」）

英語ネタのショート（`butterfly読めない`、`渋谷にYes`）で手作りした字幕の作り方を、自動作成の標準にしたもの。
自動投稿アプリの「仕上げ」（`moment_retrieval/finishing.py`）はこの方針で字幕・タイトルを焼き込む。
見た目の定数と設定の読み込みは `moment_retrieval/short_style.py` にまとめてある。

## 字幕の区切り方

- 文字起こしをそのまま流さない。**発話単位（ひと息・ひと言）の短い1行**に、開始・終了時刻を付ける。
- 区切りは自動で決める：句読点・「？」「！」の後、0.4秒以上の間（ま）、文字数（約14文字を超えたら単語の途中を避けて切る）。
- 1行の中の短い息継ぎ（0.25秒以上）は半角スペースにする（例：「嘘だろ 嘘かこれ」）。句点「。」は付けない。
- AIが字幕の文面を直すときも同じ方針：聞き間違いは直すが、**言い間違い・言い直し・口癖は言ったとおりに残す**。話していないことは足さない。
- 文面の時刻は Whisper の単語時刻に合わせ、発話区間の検出で声の出だしに寄せる（従来どおり）。

## 見た目（1080x1920基準、他の解像度は比例）

| 要素 | 大きさ | 色 | 位置（中心のy） |
|---|---|---|---|
| 字幕 | 74px・黒縁9px | 白 | 1725（画面下寄りに固定） |
| 補足字幕 | 46px・黒縁5px | 黄 | 1597（字幕の上段、別レイヤー） |
| タイトル | 92px・黒縁8px、2行 | 1行目 白、2行目（強調）黄 | 150 |
| フッター | 34px・黒縁3px | 灰 | 1870（「配信者 配信（YYYY/MM/DD）より」） |

- 字幕は1行全角14文字（約15文字）で折り返す。スペース位置を優先し、次に句読点で改行する。閉じかっこ・句読点は行頭に置かない（はみ出す行は少し横に縮めて画面内に収める）。
- 効果音が鳴る行は黄色になり、少し跳ねる（従来どおり）。
- 背景はぼかした元映像、中央に元映像（従来どおり）。

## 音声

- 1秒以上の無音（発話検出とWhisperの単語のどちらにも声がない区間）は、前後0.25秒を残して切ってつなぐ。つなぎ目は短くフェードする。
- 音量は loudnorm（I=-16 LUFS、TP=-1.5 dB、LRA=11）で揃える。

## 自動で決まるもの・設定で指定するもの

AIが決めるもの（仕上げの計画）：タイトル2行（`title_top` 白 / `title_emphasis` 黄）、字幕の文面、補足字幕（最大2つ、必要なときだけ）、効果音、冒頭・末尾の詰め。

### 全体の設定 `data/short_style.json`（無ければ既定値）

```json
{
  "streamer_name": "ゲラサブロウ",
  "footer": true,
  "ai_notes": true,
  "cut_silence": true,
  "silence_min_sec": 1.0,
  "silence_keep_sec": 0.25,
  "loudnorm": true,
  "font_name": "Yu Gothic UI"
}
```

- `streamer_name` が空なら、投稿タイトルの【名前】を使う。配信日は `source_titles.json` の配信日（yt-dlp の upload_date）。どちらも分からなければフッターは出さない。
- `ai_notes: false` でAIの補足字幕を止める（手書きの補足だけになる）。

### 1本ごとの手書き `<クリップ名>.subtitle.json`（任意）

クリップと同じフォルダに置くと、AIの案より優先される。時刻は**切り抜き範囲の先頭からの秒**（無音カット前）。

```json
{
  "title": ["butterfly が", "読めない男"],
  "footer": "ゲラサブロウ 配信（2026/11/05）より",
  "notes": [{"start": 41.9, "end": 50.2, "text": "※チャット「バターフライ」"}],
  "captions": [{"start": 0.0, "end": 1.1, "text": "待って待って"},
               {"start": 1.1, "end": 5.4, "text": "ブー…ビュー…ビターフライ？"}]
}
```

- `title` は2行目が黄色。`{"text": "...", "emphasis": true}` の形でも書ける。
- `captions` を書くと自動の字幕は使わず、書いた文面と時刻をそのまま使う。
- 作り直すときは `finish_clips.py --job <ジョブID>` を使う（`.subtitle.json` も一緒に使われる）。

## 対象外

- 英語ネタで使った「画面の一部を切り出して並べる配置（ゲーム画面＋顔カメラ）」は自動化していない。
- 編集画面（検索・編集・切り抜き）での手動保存の字幕プリセット（standard / large / boxed）は従来どおり。この方針は自動作成の仕上げに適用する。
