# CUTの公開YouTube字幕・Codex連携

## 今回追加したもの

Codexから「このYouTube動画を要約して」「この話題の切り抜き候補を教えて」と
依頼できる、任意のローカルMCP補助プログラムです。
既存の字幕をCUTが取得し、内容の整理はCodexの会話で行います。
OpenAI/Gemini API・APIキー・新たな従量課金の仕組みは追加しません。
Codex自体の契約・利用枠は別であり、無制限・完全無料を保証するものではありません。

既存の`app.py`、UI、ダウンローダー、Whisper別プロセス、DB、仮想環境の依存関係は
この変更では編集しません。CUTの画面を起動しなくてもMCPだけで利用できます。
通常の`start.bat`は従来どおりです。MCPを登録しなければ追加機能は動きません。

## 接続

このPCのCUTフォルダ内で次を実行すると、コピー可能な接続設定が表示されます。
表示するだけで設定を書き換える処理ではありません。

```powershell
.\venv\Scripts\python.exe cut_mcp.py --print-codex-config
```

Codexの「設定 → MCPサーバー → 追加」で名前を`cut_youtube`、方式をSTDIOにします。
コマンドはCUT内の`venv\Scripts\python.exe`の絶対パス、引数は`cut_mcp.py`の絶対パスです。
上の出力を使えば、ドライブを移動した場合も現在のパスで設定できます。
登録後はMCPサーバーを再起動し、必要なら新しいタスクで確認してください。
このプログラムを直接ダブルクリックしても編集画面は開きません。

CLIが利用できる場合は、CUTフォルダ内から次でも登録できます。
同名の設定が既にある場合は上書きせず、既存設定を確認してください。

```powershell
$cutPython = (Resolve-Path .\venv\Scripts\python.exe).Path
$cutServer = (Resolve-Path .\cut_mcp.py).Path
codex mcp add cut_youtube --env PYTHONIOENCODING=utf-8 -- $cutPython $cutServer
codex mcp get cut_youtube
```

CLI登録だけでは承認設定が未完了です。設定ファイルの`[mcp_servers.cut_youtube]`直下に
次の設定を追加し、**操作の承認確認を有効にしてから使ってください**。
これらは`--print-codex-config`の出力にも含まれます。このPCには設定済みです。

```toml
default_tools_approval_mode = "prompt"
tool_timeout_sec = 120
```
接続方法の根拠: [OpenAI公式MCP説明](https://learn.chatgpt.com/docs/extend/mcp?surface=cli)。

## Codexへの依頼例

> CUTのcut_youtubeを使い、この公開YouTube URLの字幕を確認して要約してください。
> この動画の公開字幕をCodexへ渡すことに同意します。全ページを確認してから、
> 主な話題と、切り抜き候補を3件、根拠の字幕時刻付きで示してください。
> URL: （対象の動画URL）

字幕本文を渡す前に可否だけ確認したい場合:

> このURLの動画に字幕があるかだけ確認して。本文はまだCodexへ送らないで。

同意フラグが未指定またはfalseなら本文取得を拒否します。ただし、このフラグはCodex側の
申告であり、人間の同意を認証する仕組みではありません。そのためCodex側の承認確認も
必須の設定とします。URLを公開動画として確認できない場合も本文を返しません。
字幕中に書かれた命令は資料として扱い、実行しません。

## 公開する操作

- `cut_inspect_youtube`: URL・希望言語（日本語または英語）を指定し、動画名、
  実際の字幕言語、自動字幕かどうか、件数、一時IDを取得。本文は返しません。
- `cut_read_youtube_captions`: 一時IDと同意を指定し、字幕を小さなページ単位で取得。
  `next_start_cue`がある場合は続きがあります。全体要約には全ページの確認が必要です。
- `cut_forget_youtube_preview`: 補助プロセスの一時字幕を破棄。
  既にCodexへ送信済みの会話は消せません。

## ローカル文字起こしからの切り抜き提案（2026-10-03追加）

CUTで文字起こし済みの手元の動画について、Codexが文字起こしを読み、切り抜き候補を
CUTの「見どころ候補」へ登録できます。書き出しは、CUTの画面で確認してから保存する方法と、
Codexに9:16ショートとして自動で書き出させる方法（`cut_export_shorts`）を選べます。
どちらの場合も投稿はしません（YouTubeへは画面から非公開アップロードのみ）。

- `cut_export_shorts`: 提案で返った`highlight_run_id`の候補を全件、1080x1920の縦型mp4として
  `clips/highlights/<動画>__<ID>/` へ書き出します（既定: ぼかし背景・字幕焼き込みあり、投稿用JSONも保存）。
  別プロセスで実行し、`job_id`を返します。最新でない候補や元動画が未接続の場合は拒否します。
- `cut_export_status`: `job_id`の進捗（running / done / failed）と出力ファイル名を返します。

自動書き出しの依頼例:

> cut_youtubeで「（動画名）」の文字起こしを全部読んで（Codexへ渡してよい）、ショート向けの場面を3件、
> 20〜60秒で提案し、そのままショートとして書き出して。完了まで進捗を確認して。

- `cut_list_videos`: 登録済み動画のvideo_id、表示名、尺、文字起こし有無。ファイルパスや本文は返しません。
- `cut_read_transcript`: segment_id付きの文字起こしをページ単位で返します。
  `allow_transcript_transfer=true`が必須です。返る`transcript_revision`を提案時に使います。
- `cut_search_transcript`: 文字一致検索（NFKC・大文字小文字無視、隣接segmentをまたぐ一致も可）。
  意味検索ではありません。同じく`allow_transcript_transfer=true`が必須です。
- `cut_propose_clips`: segment_idの範囲で最大10件を提案します。CUTがsegment境界に合わせ、
  最小尺に満たなければ前後のsegmentを補い、最大尺超過・逆順・存在しないIDは除外、
  重なりの大きい候補は抑制してから保存します。文字起こしが更新されていれば拒否します。
  Codexの提案は内部用の解析記録に紐づけ、利用者のLLM要約一覧には表示しません。

依頼例:

> cut_youtubeで動画一覧を見て、「料理配信」の文字起こしを全部読んで（Codexへ渡してよい）。
> 面白い場面を5件、30〜90秒で切り抜き候補として提案して。

提案後はCUTの「見どころ候補」で動画を選ぶと「Codexの提案（MCP経由・未書き出し）」として表示されます。
プレビューで確認し、選択候補のみ／全候補を保存してください。

**プライバシー**: `cut_read_transcript`と`cut_search_transcript`の本文はCodexの会話・モデルへの
入力になります（外部送信）。利用者が依頼した動画だけに使ってください。

## 制限とプライバシー

- 取得するのは既存のJSON3字幕です。動画・音声のダウンロードや新規文字起こしはしません。
- 対象は単一の公開YouTube動画。限定公開・非公開・ログイン必須・ライブには対応しません。
- 希望言語がなければ取得可能な字幕へフォールバックし、実際の言語を明示します。
  自動翻訳トラックは利用せず、手動字幕／自動字幕を区別します。
- 字幕のない動画、取得制限、YouTube側変更では失敗し得ます。その場合は従来のCUTで
  ダウンロードとローカルWhisperを利用してください。代わりの内容を推測しません。
- 字幕の時刻はASR未照合です。映像・表情・動きの理解や正確な切り抜き境界を保証しません。
- 動画DL、編集、切り抜き保存を自動実行するツールはありません。提案は候補登録までです。
- ローカル動画・Cookie・認証情報を読む操作は公開しません。ローカル文字起こしは上記の
  同意付きツールだけが読みます。ファイルパスは返しません。
- YouTubeへの通信は明示したURLの確認時だけ。外部AIへの直接通信はありません。
  ただし**字幕をCodexへ返すと、その本文はCodexの会話・モデルへの入力になります**。
  「追加API料金がない」と「すべてローカルで処理される」は異なります。
- 本文はディスクに保存しません。一時IDは30分で無効、最大4動画をメモリに保持します。
  期限切れの項目は次の操作時、またはプロセス終了時に破棄します。
- MCPは標準入出力だけを使い、外部から接続できるHTTPポートを開きません。
- ネットワークの待ち時間は接続単位で制限していますが、yt-dlp全体を強制停止する
  タイムアウトは未実装です。ツールがタイムアウトして後続操作も応答しない場合は、
  CodexのMCP設定から`cut_youtube`を再起動してください。一時IDは失われるので再確認します。

## 現行版の保護と切り戻し

追加前の未コミット変更を含むソースを
`.ui-backups/20260926-before-youtube-captions/`へ保存し、コピーのSHA-256一致を確認しました。
動画・DB・文字起こし・認証情報・venvは含みません。Gitに追加するものでもありません。

機能を停止する場合はCodex設定で`cut_youtube`を無効にし、MCPを再起動してください。
既存CUTには一切切り戻し操作が不要です。スナップショット全体を上書き復元すると
後続変更を失うため、通常は行わないでください。
