# Studio編集画面と旧UIの切り替え

## 目的と変更区分

OpenCutを参考に、CUTの発言検索・範囲編集に合わせたパネル配置を追加する。
これは利用者が確認するための意図的なUI変更であり、検索・編集計画・保存の
規則を変更するものではない。新しいHTTPサーバー、別のDB所有者、
OpenCutのコードや依存パッケージは追加しない。

Studioは通常起動時の配置。旧配置との速度・操作回数の比較測定は未実施であり、
アーキテクチャ計画のPhase 5性能比較gateを通過したという意味ではない。

## 起動

起動中のCUTを終了してから、次のいずれかを開く。

- `start_studio_ui.bat`: Studio配置。
- `start_classic_ui.bat`: 今回の更新直前の直感編集配置。
- `start.bat`: 既定のStudio配置（環境変数による明示指定があればそちらを使う）。

手動起動は`CUT_VIDEO_UI_LAYOUT=studio`または`classic`を設定して
`venv\Scripts\python.exe app.py`を実行する。
両配置は同じバックエンドと保存データを利用する。
同時起動して別々のUIから同じインデックスを書き換える構成ではない。

`CUT_VIDEO_ENABLE_LEGACY_UI=1`は、さらに古い「従来版（検索・切り抜き）」タブを
表示する既存の設定。今回のClassic配置とは別の切り替えである。

## Studioで確認する操作

- 検索・プレビュー・文字起こしを横に並べ、既存タイムラインを下に表示する。
- 配置設定から並び順、検索幅、文字起こし幅、パネル高さを調整する。
- 狭い画面では2列または縦積みに切り替え、ページスクロールで操作する。
- 配置の変更は表示だけに反映し、EditPlan・Undo/Redo・dirtyに含めない。
- ブラウザには配置の数値・選択肢だけを保存し、動画名・本文・パスは保存しない。
- 保存は既存の保存バーから行う。上部の導線は保存バーへの移動だけを行う。

## 保護した旧コード

`assets/app.css`と`assets/intuitive_editor.js`は更新せず維持し、Studioの見た目と
配置操作は追加のassetへ分離する。Classic起動では追加assetを読み込まない。

更新前のworking treeから実行用ソース48ファイルを
`.ui-backups/20260905-before-studio/`へ退避した。未コミットの`app.py`変更も含む。
コピー時に全ファイルのSHA-256一致を確認した。これはローカル専用の保管であり、
Git管理・配布対象には含めない。動画・DB・文字起こし・venv・認証情報は含まない。
snapshot内の`SNAPSHOT.md`に主要ファイルのhashと用途を記載している。

通常の比較や切り戻しにはClassic起動を使い、ソースsnapshotを現行ディレクトリへ
一括上書きしない。snapshot作成後の変更を消すためである。
