# 直感編集への基本機能統合メモ

> この文書は現行UIへ不足機能を統合した経緯を残すメモである。今後の責務分離、字幕出力、CLI、新UIの実施順序は [ARCHITECTURE_IMPLEMENTATION_PLAN.md](ARCHITECTURE_IMPLEMENTATION_PLAN.md) を正とする。

## 目的

直感編集は、文字起こしとタイムラインから境界を指定する操作を中心に育てる。一方、従来の検索・切り抜き画面には、正確な微調整や動画選択直後の確認など、日常的な編集に必要な基本機能が既にある。直感編集の操作が安定した段階で、それらを段階的に統合する。

このメモは将来の実装方針を残すものであり、従来画面を直ちに削除する計画ではない。

## 現在の直感編集

- 文字起こしの認識単位または発話区間から、全体開始・全体終了・除外開始・除外終了を指定できる。
- 動画全体の概要タイムラインで、拡大表示するviewportを移動・リサイズできる。
- 拡大タイムラインで境界指定、境界ドラッグ、途中カットのドラッグ追加ができる。
- 選択中の境界を一定秒数だけ前後へ移動できる。
- **対応済み:** 全体範囲・途中カット数と秒数・完成予定秒数を常時確認できる。
- **対応済み:** 途中カットを一覧から個別削除または全削除できる。
- **対応済み:** 選択した編集ツールへ、元動画プレビューの現在位置を適用できる。
- **対応済み:** 選択中の境界だけを、秒単位の時刻入力で変更できる。
- **対応済み:** 保存先フォルダをダイアログから選択できる。
- **対応済み:** サムネイル、ファイル名、長さ、ファイル名絞り込みから動画を選び、選択後は一覧を閉じて自動プレビューできる。
- 編集結果のプレビューと保存ができる。

## 統合候補と優先順

### 1. 現在再生位置から境界を設定

**対応済み。** 元動画プレビューの現在再生位置を取得し、次の操作へ適用する。

- 全体開始を現在位置に設定
- 全体終了を現在位置に設定
- 除外開始を現在位置に設定
- 除外終了を現在位置に設定

文字起こしやタイムラインと同じ編集コマンドへ変換し、別系統の状態更新処理を作らない。

### 2. 秒数調整の操作性

- `0.1 / 1 / 10 / 30 / 60 / 600` 秒などの調整幅を維持する。
- 前後ボタンを動画の近くへ配置し、選択中の境界と調整後の絶対時刻を明示する。
- キーボード操作を追加する場合も、フォーカス中の入力欄との衝突を避ける。

### 3. 動画選択時のプレビュー

- **初期対応済み:** 動画を選んだ時点で先頭発話付近を自動プレビューし、そのまま編集状態を開始する。明示的な再読み込みボタンも残す。
- ファイル名、長さ、サムネイルなど、本文を表示せず動画を識別できる情報を使う。
- **対応済み:** 動画切替時は編集nonceを更新し、前の動画に対する待機中コマンドを破棄する。連続選択は最後の選択を優先する。
- **対応済み:** サムネイル一覧は個別動画のみを表示し、選択後は自動プレビューして編集領域へ移動する。Dropdownはサムネイルを表示できない場合の予備として残す。

### 4. 文単位での境界調整

- 現在の境界付近の発話区間を取得し、前後の文境界へ移動できるようにする。
- 単語時刻がある場合でも「文単位」と「認識単位」を混同せず、操作名で粒度を明示する。
- 時刻情報がない位置を推測で作らず、保存済みASR情報の粒度に合わせる。

### 5. 選択動画内の検索から編集開始

- 直感編集画面から検索候補を読み込み、候補区間をviewportと全体範囲の初期値にする。
- 検索結果を切り抜きへ読み込んだ後も、上記の基本編集をすべて継続できるようにする。

## 設計上の注意

- `overall_start`、`overall_end`、`exclusions`、`viewport_start`、`viewport_end`を一つのcanonical stateで管理する。
- HTMLツール、文字起こし、タイムライン、秒数調整、現在再生位置の各操作を、同じFIFOコマンド経路へ集約する。
- 同一動画内ではrevision順に処理し、動画切替時はnonceが異なる古い操作を必ず破棄する。
- viewport変更は編集範囲や除外区間を変更しない。プレビューと文字起こしの表示範囲だけを更新する。
- 編集結果プレビューの連結後時刻と、元動画の絶対時刻を混在させない。境界編集は元動画モードへ戻してから行う。
- 除外区間の統合や全体範囲による切り詰め後は、選択中の境界IDを生存区間へ付け替える。
- Whisperの読み込みをGradioワーカースレッドへ戻さず、インデックス作成は引き続き別プロセスで実行する。
- テストや文書へ、動画名、個人パス、文字起こし本文などの個人情報を残さない。

## 段階的な導入方法

1. 各候補を直感編集の既存コマンドへ接続し、単体テストを追加する。
2. 境界編集、viewport操作、結果プレビュー、元動画復帰を連続して行うブラウザテストを追加する。
3. 従来画面と同じ結果になることを確認し、直感編集で不足する操作を記録する。
4. 直感編集が日常利用に十分と判断できるまでは、従来画面をフォールバックとして残す。
