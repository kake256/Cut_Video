CUT プライバシーポリシー

最終更新日: 2026年11月12日

取得する情報

CUT は、利用者が「YouTubeアカウントを連携」を行ったとき、Google の OAuth を通じて YouTube Data API へのアクセス権（アクセストークン）を取得します。利用するのは、利用者自身のチャンネルへの動画のアップロード、公開設定の変更、チャンネル名の表示、およびコメントへの返信など、利用者が CUT で指示した操作に必要な範囲だけです。

保存場所

アクセストークン、動画、文字起こし、設定はすべて利用者の PC（CUT のフォルダ内の data/ など）にだけ保存されます。開発者のサーバーへ送信・保存することはありません。開発者がこれらの情報を見ることはできません。

第三者への提供

取得した情報を第三者に販売・提供することはありません。YouTube への投稿は、利用者の指示で Google（YouTube）へ直接送信されます。見どころの選定に利用者が Claude Code や Codex などの AI を設定した場合、文字起こしの一部がその AI の提供元へ送られます。その扱いは各提供元の規約に従います。

Google ユーザーデータの扱い

CUT による Google API から受け取った情報の使用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。YouTube の利用には YouTube 利用規約 と Google プライバシーポリシー が適用されます。

連携の解除

CUT の「設定」タブで連携を解除すると、PC に保存したトークンを削除します。Google アカウントの権限ページ からもアクセス権を取り消せます。
