# CUT 自動投稿（別アプリ）

`start_auto_publish.bat` で起動します（http://127.0.0.1:7870 、編集用のCUTとは別ウィンドウ）。
編集用のCUT（`start.bat`）と同じライブラリ（`data/`）と保存先（`clips/`）を使うので、両方同時に開いて構いません。

動画のURL（YouTube / Twitch など）か、動画フォルダ内のファイルを貼り付けると、次の流れを裏で自動実行します。

1. 取り込み: URLならダウンロード（元動画のチャンネルも記録）
2. 文字起こし: 文字起こし済みなら再利用
3. 候補選び: 選んだAI（Codex / Claude Code）がCUTのMCPツールだけで文字起こしを読み、場面を提案
4. 書き出し: 9:16ショート（1080x1920）、字幕焼き込み、投稿用JSON付き
5. 投稿: YouTubeへ**非公開**でアップロード（アカウント未連携なら書き出しで終了）

公開は自動では行いません。ジョブ一覧の「公開する」でワンクリック公開できるのは、
**許可済みチャンネル**または**この動画のみの明示的な許可**に一致する動画だけで、1日の公開上限（既定3本）の範囲内です。

## 準備

- YouTube: `docs/YOUTUBE_UPLOAD.md` の手順でOAuthクライアント（デスクトップアプリ）を作り、ダウンロードしたJSONを
  アプリの「OAuthクライアントJSON」から読み込んでから「YouTubeアカウントを連携」を押す。
  連携には「アップロード」と「チャンネル名の読み取り」の許可を求めます。
- AI: Codex（デスクトップ版に同梱のCLIを自動で探します）か Claude Code（`claude`）がログイン済みであること。
  - Codexは読み取り専用のサンドボックスで実行し、CUTのMCPツールの承認だけをこの実行に限って自動にします。
  - Claude Codeは `--strict-mcp-config` でCUTのMCPだけを読み込み、許可するツールを4つに限定します。

## 公開許可

- 「チャンネル全体」は、チャンネルページかその動画のURLを登録し、そのチャンネルの動画を公開対象にします。既存の登録もこの扱いです。
- 「この動画のみ」は動画ページのURLを登録し、yt-dlpが取得した**動画IDと元チャンネルIDの両方**が一致するジョブだけを公開対象にします。同じチャンネルの別動画は公開できません。
- どちらも「許可の根拠」（配信者のガイドラインURL、許可をもらった日時など）が必須です。チャンネル全体の登録は `data/auto_publish_channels.json`、動画限定の登録は `data/auto_publish_videos.json` に保存されます。
- 元動画のチャンネルが不明なもの（ローカルファイル、YouTube/Twitch以外）は公開できません。

## 記録とファイル

- ジョブ: `data/auto_jobs/*.json`（アプリ再起動時に実行中だったジョブは「失敗」として残ります）
- 公開履歴（1日の上限の計算用）: `data/auto_publish_log.json`
- 書き出した動画: `clips/highlights/<動画名>__<ID>/`

## 注意

- 文字起こしは選んだAIの提供元へ送信されます。
- 審査（監査）を受けていないGoogle APIプロジェクトでは、YouTubeが動画を非公開に固定するため「公開する」が失敗します。
- 他人の配信は、許可やガイドラインを確認したチャンネルだけを許可済みにしてください。
