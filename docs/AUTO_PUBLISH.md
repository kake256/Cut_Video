# CUT 自動投稿（別アプリ）

`CUT_auto_publish.vbs`（またはデスクトップの「CUT 自動投稿」ショートカット）で起動すると、専用のウィンドウで開きます。コンソール画面は出ず、ウィンドウを閉じるとアプリも終了します（実行中のジョブがあれば確認します）。
ショートカットは `make_shortcut.bat` で作れます。`start_auto_publish.bat` はログを見たいとき用で、`--browser` を付けるとブラウザで開きます（http://127.0.0.1:7870 、編集用のCUTとは別）。
編集用のCUT（`start.bat`）と同じライブラリ（`data/`）と保存先（`clips/`）を使うので、両方同時に開いて構いません。

動画のURL（YouTube / Twitch など）か、動画フォルダ内のファイルを貼り付けると、次の流れを裏で自動実行します。

1. 取り込み: URLならダウンロード（元動画のチャンネルも記録）
2. 文字起こし: 文字起こし済みなら再利用
3. 候補選び: 選んだAI（Codex / Claude Code）がCUTのMCPツールだけで文字起こしを読み、場面を提案
4. 書き出し: 9:16ショート（1080x1920）、字幕焼き込み、投稿用JSON付き
5. 投稿: YouTubeへ**非公開**でアップロード（アカウント未連携なら書き出しで終了）

公開は自動では行いません。ジョブ一覧の「公開する」でワンクリック公開するか、YouTube Studioで公開します。

**前提:** このアプリは、権利者から切り抜きの許可を得た動画（自分の配信を含む）に使うことを前提にしています。
アプリ側では許可の登録や確認を行いません。第三者の音楽・映像が含まれる場合は、公開前に確認してください。

## 画面

- **切り抜き**タブ: URLを貼り、AI（Codex / Claude Code）・モデル・本数を選んで「切り抜いて非公開アップロード」を押します。
  Codexのモデルは既定で GPT-6-Luna、推論の強さは「長さ・レイアウト・アップロード・推論の強さ」で選べます（既定 high）。
  選んだモデルはそのジョブだけに使い、`~/.codex/config.toml` は書き換えません。
  長さ（既定 20〜180秒、最長はショートの上限の180秒）・縦型レイアウト・アップロードの有無も同じ欄にあります。
- 「切り抜き」タブでは、URLの代わりに**文字起こし済みの動画**（編集用CUTで処理した動画も含む）を一覧から選べます。
- **インデックスの共有**タブ: 文字起こしを共有zipで書き出し（元動画URLを同梱）、または読み込みます。
  読み込み時に「続けて切り抜き」をオンにすると、元動画のダウンロード → 共有された文字起こしへの関連付け
  （Whisperは動かさない）→ 切り抜き → 非公開アップロードまで進みます。
  URLを貼ったジョブでも、同じ動画の共有インデックスを読み込み済みなら自動で関連付けます。
- **設定**タブ: YouTubeアカウント連携、Google Cloudの準備、配布用の同梱。

## 仕上げ（引きのタイトル・字幕のタイミング調整・効果音）

「長さ・レイアウト・仕上げ…」の「仕上げる」がオン（既定）だと、書き出した各ショートを次のように仕上げ直してからアップロードします。
- 画面上部に、AIが考えた「引き」のタイトル（14文字以内）を表示
- 字幕の文面はAIが整える（聞き間違いの修正・句読点・意味のまとまりで区切る）。表示の時刻はWhisperの単語時刻に対応付け、
  さらに動画ごとに記録した発話区間（下の「盛り上がりの手がかり」を参照）に合わせて開始・終了を補正する。
  AIの文面が元の発言とかけ離れている場合は、Whisperの文字起こしから字幕を作る
- 盛り上がる瞬間に効果音（ポン・チーン・ドン・シュッ・ヒュイッ。ffmpegで合成、外部素材なし）を入れ、その瞬間の字幕を黄色で強調
- 冒頭・末尾の無言を最大3秒ずつ詰める

仕上げの内容は各動画の隣の `.finish.json` に残ります。計画が取れなかった場合は、タイトルと字幕調整だけ行います。
既存の書き出しに試すときは `venv\Scripts\python.exe finish_clips.py --job <ジョブID>`（元の動画は変えず `_finished.mp4` を作成）。

## 探したい場面を指定する

「切り抜き」タブの「探したい場面（任意）」に、例えば「謎解きができなくてキレている箇所」のように書くと、
AI（Codex / Claude / ローカル）はそれに当てはまる場面だけを選びます。当てはまる場面が少なければ本数未満になり、
1件もなければジョブは「当てはまる場面が見つかりませんでした」で終わります。空欄なら従来どおり見どころ全般から選びます。

## 盛り上がりの手がかり（音声の波形・コメント履歴）

文字起こしに加えて、次の時系列を動画ごとに `data/signals/` に記録し、見どころを選ぶAIに「盛り上がりの手がかり」として渡します。
AIには、これだけを理由に選ばず、文字起こしの内容と合わせて判断するよう指示しています。

- 音声の波形: 0.1秒ごとの音量と発話区間（faster-whisper同梱のSilero VAD、別プロセスで実行）。文字起こしの直後に記録し、
  文字起こし済みの既存の動画は次に切り抜くときに1回だけ解析します（7時間の配信で約2分半）。
  周囲より急に大きな音（叫び声・笑い声など）を最大10か所渡し、発話区間は字幕の時刻補正にも使います。
- コメント履歴: 元の配信のURLが分かる動画（URLから取り込んだもの・共有zipで受け取ったもの）は、初回の切り抜き時に取得します。
  - YouTube: 配信アーカイブのチャットのリプレイ（yt-dlp）。投稿動画やリプレイのない配信では使いません。
  - Twitch: VODのチャット。公式APIがないため、twitch.tvのサイトが使う公開の窓口から時刻順に取得します。
    Twitch側の仕様変更で取得できなくなる場合があり、その場合はコメントなしで続行します。
  - 30秒ごとのコメント数が普段の2.5倍以上になった箇所を最大10か所、多かったコメント例（各20文字まで）と一緒に渡します。
    コメントは出来事の後に増えるので、10秒前を指します。

## 同じ動画を何度も切り抜くとき

YouTubeへのアップロードに成功した切り抜きは、その動画の「投稿済みの範囲」として記録されます。
同じ動画で次に切り抜くと、AI（Codex / Claude / ローカル）に投稿済みの範囲を伝えて重ならない場面を選ばせ、
それでも重なる提案（短い方の30%以上が重なるもの）はCUTが保存前に除外します。
投稿済みの範囲は共有zipにも入り（時刻とタイトルのみ。YouTubeの動画IDは含みません）、受け取った側でも同じように避けます。
書き出しただけでアップロードしていない切り抜きは記録されないので、後から候補にできます。

## 見どころを選ぶAI

「設定」タブの「見どころを選ぶAI」で、各AIの状態確認とセットアップができます（使うものだけで十分です）。

| ボタン | 必要なもの |
|---|---|
| Codex | ChatGPTアカウント（Node.jsが無ければ先に入れます） |
| Claude | Claudeアカウント |
| ローカル | アカウント不要・数GBのダウンロード・メモリ16GB程度（setup_ollama.bat を実行） |

ボタンは、未インストールならインストール、未ログインならログイン、準備済みなら何もしない、を自動で判断します。
インストールとログインは別ウィンドウで進み、ブラウザでのログインが必要なものは自動で開きます。
ローカルAIは文字起こしをPCの外に出しません。選定の質はCodex/Claudeより下がることがあります。

## 準備

- YouTube: `docs/YOUTUBE_UPLOAD.md` の手順でOAuthクライアント（デスクトップアプリ）を作り、ダウンロードしたJSONを
  アプリの「OAuthクライアントJSON」から読み込んでから「YouTubeアカウントを連携」を押す。
  連携には「アップロード」と「チャンネル名の読み取り」の許可を求めます。
- AI: Codex（デスクトップ版に同梱のCLIを自動で探します）か Claude Code（`claude`）がログイン済みであること。
  - Codexは読み取り専用のサンドボックスで実行し、CUTのMCPツールの承認だけをこの実行に限って自動にします。
  - Claude Codeは `--strict-mcp-config` でCUTのMCPだけを読み込み、許可するツールを4つに限定します。

## 記録とファイル

- ジョブ: `data/auto_jobs/*.json`（アプリ再起動時に実行中だったジョブは「失敗」として残ります）
- 書き出した動画: `clips/highlights/<動画名>__<ID>/`
- 音声の波形・コメント履歴: `data/signals/<動画のID>.audio.json` / `.chat.json`（消しても次に使うときに作り直します）

## 注意

- 文字起こしは選んだAIの提供元へ送信されます。盛り上がりの手がかりとして、コメントの例（数件・各20文字まで）も送信されます。
- 審査（監査）を受けていないGoogle APIプロジェクトでは、YouTubeが動画を非公開に固定するため「公開する」が失敗します。
- 以前の版で作られた `data/auto_publish_channels.json` / `auto_publish_videos.json` / `auto_publish_settings.json` /
  `auto_publish_log.json` は使われなくなりました（残っていても動作に影響しません。不要なら削除して構いません）。
