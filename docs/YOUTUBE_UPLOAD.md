# YouTubeへの非公開アップロード

CUTで保存した切り抜き動画を、あなた自身のYouTubeチャンネルへ**非公開**でアップロードします。
公開設定はCUTからは変えません。YouTube Studioで内容を確認してから、あなたが公開してください。

## 一度だけ行う準備（あなたの操作が必要です）

**かんたんな方法（Google Cloud SDK が入っている場合）:** 自動投稿アプリ（`start_auto_publish.bat`）の
「① アカウント連携 → Google Cloudの準備」で、ログイン・プロジェクト作成・YouTube Data API v3 の有効化を
ボタンで行えます。プロジェクトの作成は同意のチェックを入れたときだけ実行されます。
その後「3. 設定ページを開く」で開くページで、下の手順3〜5（同意画面、テストユーザー、OAuthクライアント）を行ってください。
作成したプロジェクトIDは `data/youtube_gcp_project.json` に記録されます。

**手作業で行う場合:**

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成します。
2. 「APIとサービス」→「ライブラリ」で **YouTube Data API v3** を有効にします。
3. 「OAuth同意画面」を設定します。
   - User Type は「外部」。アプリ名・サポートメールを入力します。
   - スコープは追加しなくて構いません（CUTは連携時に `youtube.upload`、連携先チャンネル名の表示用の `youtube.readonly`、公開ボタン用の `youtube`（YouTubeアカウントの管理）を要求します）。
   - 「テストユーザー」に、アップロード先チャンネルのGoogleアカウントを追加します。
4. 「認証情報」→「認証情報を作成」→「OAuthクライアントID」→ 種類は **デスクトップアプリ** を選びます。
5. 作成したクライアントのJSONをダウンロードし、自動投稿アプリ（`start_auto_publish.bat`）の
   「OAuthクライアントJSON」から読み込みます。手動で置く場合は次の名前にします。

   ```
   data/youtube_client_secret.json
   ```

   `data/` はGit管理外です。このJSONは他人に渡さないでください。

## 使い方

1. 「LLM要約・見どころ」→「② 要約から見どころを作る・切り抜く」で候補を保存します。
   投稿用のタイトル・説明・タグを使いたい場合は「動画と同名の投稿用JSONを保存する」をオンにします。
2. 「YouTubeへ非公開アップロード（任意）」を開き、内容と権利の確認にチェックしてボタンを押します。
3. 初回だけブラウザが開き、Googleアカウントの許可を求められます。許可するとトークンが
   `data/youtube_token.json` に保存され、次回からは不要です。
4. ログに表示されるYouTube StudioのURLから内容を確認し、公開設定を変更します。

## 仕様と制限

- アップロードは常に `private`（非公開）です。
- タイトル・説明・タグは投稿用JSON（`<動画名>.metadata.json`）を優先し、なければファイル名をタイトルにします。
  YouTubeの制限に合わせ、タイトルは100文字に切り詰め、`<` `>` は除去します。
- アップロード済みの動画には `<動画名>.youtube.json` が作られ、同じ動画を二重にアップロードしません。
- 審査（監査）を受けていないAPIプロジェクトからのアップロードは、YouTube側でも非公開に固定されます。
  公開できない場合は、YouTube Studioの表示とGoogleの監査手続きを確認してください。
- YouTube Data APIの1日あたりの割り当て（既定10,000ユニット）では、アップロードは1日6本程度が上限です。
- 縦長で3分以内の動画は、YouTube側でショートとして扱われます。
- 他人の配信を切り抜く場合は、配信者の許可・切り抜きガイドラインを必ず確認してください。

## 連携を止める・アカウントを切り替える

- `data/youtube_token.json` を削除すると、次回アップロード時に再度ログインを求められます。
- Googleアカウントの「サードパーティ製のアプリとサービス」からアクセス権を取り消せます。

## コメントへの定型文自動返信（2026-10-13追加・新規要件）

自動投稿アプリの「コメント返信」タブで、自分のチャンネルの動画に付いた新しいトップレベルコメントへ
定型文で自動返信します（承認なし）。実装は `moment_retrieval/youtube_auto_reply.py`。

- 準備: 上の手順で読み込んだOAuthクライアント（`data/youtube_client_secret.json` または同梱クライアント）をそのまま使います。
  「返信用に連携」を押すとブラウザで `youtube.force-ssl`（コメントの管理）の許可を求められます。
  トークンはアップロード用とは別の `data/youtube_reply_token.json` に保存されるため、アップロードの連携には影響しません。
- 定型文は入力欄に書いて「追加」を押すと1件ずつ登録され、改行を含む文もそのまま返信します。一覧から選んで削除できます。
  毎回ランダムに選び、直前と同じ文は避けます。`{name}` は相手の表示名に置き換わります。
- 上限: 1日 `3` 件（設定で1〜20件）、1回の確認で1件、返信どうしは10分以上あけます。確認間隔の既定は30分です。
- 「過去の未返信コメントも対象にする」（既定オン）では、新しい方から最大1,000スレッドを確認し、未返信のものに古い順で返信します。
  オフにすると、設定を初めて保存した時刻より後のコメントだけが対象です。
- 対象外: 自分のコメント、自分が既に返信したスレッド、返信できないスレッド。
- YouTube Data APIにはコメントへハート（クリエイターのハート）を付ける機能がないため、ハートはYouTube Studioで付けてください。
- 返信済み・失敗したコメントIDは `data/youtube_auto_reply.db` に記録し、二重に返信しません（失敗したものも再試行しません）。
  設定は `data/youtube_auto_reply.json` です。
- このパソコンで動かす場合は、アプリを開いている間だけ動きます。止めるには「自動返信を有効にする」を外して保存します。

### パソコンを起動していなくても返信する（GAS）

「コメント返信」タブの「GASで動かす（作成・更新）」を押すと、あなたのGoogleアカウントに
Google Apps Script のプロジェクト「CUT コメント自動返信」を作り、Googleのサーバー上で同じ規則のまま返信します
（実装: `moment_retrieval/youtube_gas.py`、GAS側のコード: `moment_retrieval/gas/Code.js`）。

YouTubeへは「返信用に連携」で選んだチャンネルのログイン（更新トークン）を使って返信します。GASは
管理者の個人アカウントで動きますが、このログインを使うので**ブランドアカウントのチャンネルでも返信できます**。
ログイン情報はスクリプト内の `Secret.gs` に書き込まれます（あなたのGoogleアカウント内だけ。スクリプトを他人と共有しないでください）。

前提: OAuth同意画面を「本番環境」にしておきます（Google Cloud Console →「Google Auth Platform」→「対象」→
「アプリを公開」）。「テスト中」のままだとログインの有効期限が7日で切れ、GASからの返信が止まります。
公開後は、ログイン時に「Google で確認されていません」の警告が出ます（「詳細」→「移動」で進めます）。
公開する前に連携したログインは期限付きのままなので、公開後に「返信用に連携」をやり直してください。

初回だけ必要な操作（Googleの仕様で、本人以外は行えません）:

0. 「返信用に連携」を押し、返信に使うチャンネル（ブランドアカウントならそのチャンネル）を選んで許可します。
1. ブラウザが開いたら、Googleアカウントでログインして「許可」を押します（スクリプトを作る許可。`script.projects` / `script.deployments`）。
   トークンは `data/youtube_gas_token.json` に保存されます。
2. 「Apps Script APIがオフ」と表示された場合は、開いたページ（https://script.google.com/home/usersettings ）で
   「Google Apps Script API」をオンにして、もう一度ボタンを押します。
   「Google CloudプロジェクトでApps Script APIが無効」と表示された場合は、開いたページで「有効にする」を押します
   （Google Cloudの準備ボタンで作ったプロジェクトなら、自動で有効になっています）。
3. 次に開くページで、もう一度Googleアカウントを選んで「許可」を押します（スクリプトが外部（YouTube）へ接続し、
   定期実行とログ用スプレッドシートを作る許可）。「このアプリは Google で確認されていません」と出たら「詳細」→「移動」を選びます。
   完了ページに、返信に使うチャンネル名と返信ログ（スプレッドシート）へのリンクが表示されます。
   「現在、ファイルを開くことができません」と表示される場合は、ブラウザで複数のGoogleアカウントにログインしていて、
   別のアカウントが優先されています。https://script.google.com/d/<スクリプトID>/edit （アプリの「スクリプトを開く」）を開き、
   連携したアカウントに切り替えてから、関数「setup」を選んで「実行」→「許可」を行ってください。

その後:

- 定型文や上限、有効/無効を変えると、GASのスクリプトの設定（`Config.gs`）も自動で書き換えます。
- GASで動かしている間は、このパソコンからは返信しません（二重に返信しないため）。
- 「このパソコンで動かすに戻す」を押すと、GAS側の返信を止めます。プロジェクト自体は消さないので、
  不要なら https://script.google.com から削除してください。
- 返信済みのコメントや日次の件数は、GAS側のスプレッドシートとこのパソコンのログで別々に数えます。
  同じ日に切り替えると、その日だけ上限を少し超えることがあります。
- GASのログインと許可（手順1と3）は、ブランドアカウントではなく、管理している個人のGoogleアカウントで行います
  （ブランドアカウントではGASを開けず、403になります）。完了ページのチャンネル名が返信先のチャンネルか確認してください。
- 「返信用に連携」をやり直すと、新しいログインをGASにも自動で書き込みます。

## 他の人に使ってもらう（OAuthクライアントの同梱）

1. 上の手順で自分のOAuthクライアントを作り、自動投稿アプリで読み込みます。
2. 「配布用: OAuthクライアントをアプリに同梱」→「このクライアントをアプリに同梱する」を押すと、
   アプリフォルダに `youtube_oauth_client.json` が作られます（Git管理外）。
3. 使う人のGoogleアカウントを、Google Cloud Consoleの「対象」ページでテストユーザーに追加します
   （Googleの審査を受けるまでは最大100人）。
4. CUTのフォルダごと渡します。受け取った人は「YouTubeアカウントを連携」を押すだけで、自分のチャンネルへ投稿できます。
   ログイン情報（`data/youtube_token.json`）は各自のPCにだけ保存されます。

注意:
- `youtube_oauth_client.json` は公開リポジトリ（GitHub等）に載せないでください。配布はフォルダの受け渡しで行います。
- 使う人が自分のクライアントを読み込んだ場合は、そちらが優先されます。
- 別の場所に置く場合は、環境変数 `CUT_YOUTUBE_CLIENT_FILE` でファイルの場所を指定できます。
