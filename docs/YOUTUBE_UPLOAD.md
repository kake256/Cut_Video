# YouTubeへの非公開アップロード

CUTで保存した切り抜き動画を、あなた自身のYouTubeチャンネルへ**非公開**でアップロードします。
公開設定はCUTからは変えません。YouTube Studioで内容を確認してから、あなたが公開してください。

## 一度だけ行う準備（あなたの操作が必要です）

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成します。
2. 「APIとサービス」→「ライブラリ」で **YouTube Data API v3** を有効にします。
3. 「OAuth同意画面」を設定します。
   - User Type は「外部」。アプリ名・サポートメールを入力します。
   - スコープは追加しなくて構いません（CUTは連携時に `youtube.upload` と、連携先チャンネル名の表示用に `youtube.readonly` を要求します）。
   - 「テストユーザー」に、アップロード先チャンネルのGoogleアカウントを追加します。
4. 「認証情報」→「認証情報を作成」→「OAuthクライアントID」→ 種類は **デスクトップアプリ** を選びます。
5. 作成したクライアントのJSONをダウンロードし、自動投稿アプリ（`start_auto_publish.bat`）の
   「OAuthクライアントJSON」から読み込みます。手動で置く場合は次の名前にします。

   ```
   data/youtube_client_secret.json
   ```

   `data/` はGit管理外です。このJSONは他人に渡さないでください。

## 使い方

1. 「LLM要約・見どころ」→「② 要約から見どころを作る・切り抜く」で候補を保存します。
   投稿用のタイトル・説明・タグを使いたい場合は「動画と同名の投稿用JSONを保存する」をオンにします。
2. 「YouTubeへ非公開アップロード（任意）」を開き、内容と権利の確認にチェックしてボタンを押します。
3. 初回だけブラウザが開き、Googleアカウントの許可を求められます。許可するとトークンが
   `data/youtube_token.json` に保存され、次回からは不要です。
4. ログに表示されるYouTube StudioのURLから内容を確認し、公開設定を変更します。

## 仕様と制限

- アップロードは常に `private`（非公開）です。
- タイトル・説明・タグは投稿用JSON（`<動画名>.metadata.json`）を優先し、なければファイル名をタイトルにします。
  YouTubeの制限に合わせ、タイトルは100文字に切り詰め、`<` `>` は除去します。
- アップロード済みの動画には `<動画名>.youtube.json` が作られ、同じ動画を二重にアップロードしません。
- 審査（監査）を受けていないAPIプロジェクトからのアップロードは、YouTube側でも非公開に固定されます。
  公開できない場合は、YouTube Studioの表示とGoogleの監査手続きを確認してください。
- YouTube Data APIの1日あたりの割り当て（既定10,000ユニット）では、アップロードは1日6本程度が上限です。
- 縦長で3分以内の動画は、YouTube側でショートとして扱われます。
- 他人の配信を切り抜く場合は、配信者の許可・切り抜きガイドラインを必ず確認してください。

## 連携を止める・アカウントを切り替える

- `data/youtube_token.json` を削除すると、次回アップロード時に再度ログインを求められます。
- Googleアカウントの「サードパーティ製のアプリとサービス」からアクセス権を取り消せます。
